Como preparar no computador

O projeto original valida Linux; a versao Windows continua sem validacao publica. Para compilar, e necessario um dump proprio da versao americana SLUS-00583.

git clone --recurse-submodules https://github.com/jogoiarexx-blip/DUKE-NUKEN-RECOMP.git
cd DUKE-NUKEN-RECOMP
python3 -m venv .venv
.venv/bin/pip install -r recomp/requirements-local.txt
# Coloque a imagem do seu disco em game/
.venv/bin/python recomp/tools/local/build.py --jobs 4
python3 recomp/tools/local/run.py

Antes de compilar, confira as dependencias para seu sistema e as notas de estado do desenvolvimento.
